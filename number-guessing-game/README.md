# Number Guessing Game

Tallgjettespill i Python der spilleren skal gjette et tilfeldig tall generert av datamaskinen innenfor et bestemt område (f.eks. 1 til 100). Kjøres i terminalen.

## Krav & Kjøring
- Python 3
- Python `random`-modul (innebygd)
```powershell
python game.py
```
