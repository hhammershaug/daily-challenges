# Quiz Game

quiz-spill i Python med poengtelling. Kjøres i terminalen. 

## Krav & Kjøring
- Python 3
- Python
```powershell
python game.py
```

## Slik spiller du
1. Svar `yes` for å starte.
2. Svar på spørsmålene om CPU og RAM.
3. Store/små bokstaver har ingenting å si (`.lower()` håndterer dette).
4. Spillet teller +1 score hvis riktig svar, viser sluttscore til slutt (f.eks. `score = 2/2`).
