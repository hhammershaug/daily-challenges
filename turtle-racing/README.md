# 🐢 Turtle Racing Game

A graphical 2D racing game built using Python's built-in `turtle` module. Players choose the amount of racers, and the turtles sprint randomly toward a red finish line.

## 🚀 Features
* **Dynamic Player Count**: Supports between 2 and 10 autonomous racers.
* **Randomized Outcomes**: Every race uses randomized speeds for the turtles.
* **Visual Scoreboard**: Displays the winning turtle color directly on the screen.

---

## 🛠️ How to Run
```bash
# Navigate to the game directory
cd daily-challenges/turtle-racing-game

# Run the game
python game.py
```

---

## 🕹️ Controls & Gameplay
1. Enter the number of racers (2-10) in your terminal.
2. Watch the countdown in the terminal.
3. The graphical window will pop up and start the race!
4. Check the on-screen trophy text to see who won.
